## 🚀 Things I've built

### 📚 LearnTrace

An **AI-powered assessment and learning platform** that helps teachers evaluate student answers and identify where students are struggling.

- 📝 Teachers can upload **answer keys as text or handwritten images**
- 🔍 Uses **OCR** to extract text from handwritten submissions
- 🤖 AI evaluates answers against the answer key and generates **scores with reasoning**
- ⚠️ Uncertain evaluations can be **flagged for teacher review**
- 🧠 Identifies **concept-level learning gaps** instead of showing only a final score
- 📊 Provides teachers with insights into student performance
- 🔄 Generates **revision suggestions** based on identified weak areas

**Built with:** `React` `Vite` `FastAPI` `Python` `Groq API` `GPT-OSS-20B` `OCR`

### 🤖 AI Study Planner

A conversational **AI study-planning assistant** that turns a student's goals and available time into a structured, personalized study plan.

- 💬 Students interact with the planner through a **chat-based interface**
- 📅 Generates **day-by-day study schedules**
- 🎯 Breaks larger goals into **manageable topics and tasks**
- 🔁 Suggests **revision and practice strategies**
- 🧩 Uses carefully designed prompts to make plans more **personalized and actionable**

**Built with:** `Dify Cloud` `Groq API` `GPT-OSS-20B` `Prompt Engineering`

### 📧 Email Spam Detection

A machine learning project that classifies emails as **spam or legitimate** by learning patterns from their text content.

- 🧹 Cleans and preprocesses **raw email text**
- 🔤 Converts text into **machine-readable features**
- 🤖 Trains a classification model to distinguish **spam from legitimate emails**
- 📊 Evaluates model performance using classification metrics
- 🔎 Uses learned text patterns to make predictions on **new, unseen emails**

**Built with:** `Python` `Machine Learning` `NLP` `Text Preprocessing` `Feature Extraction`
